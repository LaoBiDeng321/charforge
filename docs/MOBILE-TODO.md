## 当时的取舍（一句话备查）

- **为什么是 1280**：现网断点 1024 / 768 / 380，1280 > 1024 ⇒ PC 样式全量生效，不触发任何移动断点。
- **为什么不做真响应式**：`fullpage.js` 的全屏滚动与触摸手势天然冲突，移动端要舒服就得换成单列文档流 —— 那是结构性改造，不是调 CSS 能解决的。
- **2026-09-20 为什么最终选了"面板全屏化"**：前两版都试过、都不行 —— 写死 `font-size: 16px` 仍会被放大（PC 视图整页缩到约 0.3 倍，16px 实际只剩 ~5pt）；动态补偿字号挡住了放大，但输入框被撑成 ~60px 的巨无霸，观感不能接受。最终把问题从"单个输入框"改成"整块面板"，实现见下。

## 什么时候该重新考虑

- 有排期做真响应式时：从 `DEPLOY.md` 记录的推荐顺序第 1 条（**换掉全屏滚动**）动手，收益最大。
