## 这是什么

**CHAR//FORGE** —— 角色扮演 Skill 资源站。纯静态，全部以 Markdown 交付，可下载、可修改、可自部署。

仓库里有两类产物：

- **角色构建器**（`skills/`）—— 方法层。教你（或 AI）怎么把一部作品里的角色、或一个原创角色，做成一套可扮演的设定。
- **角色卡**（`char/`）—— 成品层。一人一个目录，10 个各司其职的设定文件 + `assets/` 立绘，直接给扮演用的 agent 加载。

## 三层职责（一句话版）

| 层 | 位置 | 谁看 | 只写什么 |
|---|---|---|---|
| **项目层** | 根 `README.md` · `docs/` | 维护者、站点使用者 | 怎么跑怎么发、目录结构、交付契约、构建行为 |
| **构建器层** | `skills/<slug>/`（随 ZIP 下发） | 用构建器产角色的人 | 只写"如何构建一个角色设定" |
| **角色层** | `char/<slug>/`（随 ZIP 下发） | **扮演该角色的 agent** | 只有扮演必需的：运行规则 + 设定文件 + 立绘 |

完整规则（跨层内容往哪抬、构建器禁止包外链接、下载包边界）见 [`LAYERS.md`](LAYERS.md)。
