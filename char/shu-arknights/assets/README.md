# 黍 · 外貌参考资源（assets/）

## 一、用途声明

本文件夹存放**角色立绘与外貌参考图**，供多模态模型在扮演启动时读取，建立"我长什么样"的外貌认知（加载规则见 `../SKILL.md` 的加载顺序条目）。

- 纯文本模型可忽略本文件夹，不影响扮演。
- 本文件夹**不计入 10 个设定文件**：图片不是设定，只作外貌锚点；外貌文字要点见 `../profile.md`「外观」节。

## 二、资源限制说明

- 绝大多数素材站有下载限制（**登录 / 反爬 / 版权**），本 skill **默认不自动抓取图片**，由用户手动下载后放入本文件夹。
- 本 skill 只输出放置说明，**不代下载、不代转存**。
- 请优先使用**官方渠道**；非官方转存或"画质提升"版本请自行确认版权与清晰度，本 skill 不对其授权状态负责。

## 四、命名规范

- 新增文件统一格式：`<序号>-<内容>.<扩展名>`（序号两位、内容用中文短名），例如：
  - `03-多角度-三视图.png`
  - `04-表情-无奈.png`
  - `06-道具-玉琮.png`
- **既有文件保留原名**（`黍-默认-立绘.png`、`黍-春日宴-立绘.png`、`黍-春日宴-立绘-全图.jpg`、`明日方舟立绘_黍_1.png`）：`../profile.md`「外观」节已按原名引用，重命名会造成引用失效；如需统一命名，须同步改该处引用。
- 同一角色的更新版本用 `-v2` 后缀，不覆盖旧图。
