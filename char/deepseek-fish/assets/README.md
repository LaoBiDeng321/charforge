# assets/README.md —— 外貌参考放置说明

## 用途声明

本文件夹存放角色「吃白饭的大肥鱼」的外貌参考图，供多模态模型在扮演时建立"我长什么样"的外貌认知。模型加载本目录后应将图片作为外貌锚点，与 profile.md 外观查表互为补充（冲突时以图片为准）。

## 资源限制说明

绝大多数素材站有下载限制（登录 / 反爬 / 版权），本 skill **不自动抓取图片**，由用户手动下载后放入本文件夹。放入后无需改代码，模型按文件名自动识别。

**重要授权提醒**：本角色形象源自「溟月」，原型以 **CC BY-NC-SA 4.0** 授权开放二创（署名、非商业使用、相同方式共享）。取图时请在图片同目录保留来源说明，勿将本目录图片用于商业用途。
