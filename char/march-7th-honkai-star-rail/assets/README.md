# 三月七（含长夜月）· 外貌参考资源

## 用途声明

本文件夹存放角色官方立绘、光锥画面与卡片图，供**多模态模型**在扮演启动时建立“我长什么样”的外貌认知。纯文本模型可忽略本目录；目录为空或缺失时静默跳过，不影响文本扮演。

## 资源限制说明

- 本目录中的图片由使用者手动投放；**立绘/光锥/卡片图的社区整理链接见下方「立绘与图片来源」**，缩略图/官方表情包见 `thumbnails/README.md`。
- 素材站通常有登录、反爬与版权限制，本 skill 不自动抓取图片。
- 若你是其中某张图的作者并希望署名或下架，请按仓库根 `README.md` 的免责声明提 Issue；收到即处理。

- **三月七系列立绘、巡猎立绘、时装与光锥画面**：来自社区整理帖 [《三月七立绘》（米游社文章 63931061）](https://www.miyoushe.com/sr/article/63931061)。

- **Q 版头像 / 缩略图**：用户说明为**官方表情包**（具体套组未记录）。

> 上述两篇为社区整理帖，不是官方发布页；图片本体按官方物料使用，版权归米哈游所有。整理帖只作为“当前获取渠道”的记录，不改变图片的官方属性判断。
