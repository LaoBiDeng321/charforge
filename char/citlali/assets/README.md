# assets/README.md —— 外貌参考放置说明

## 用途声明

本文件夹存放角色「茜特菈莉」的外貌参考图，供多模态模型在扮演时建立"我长什么样"的外貌认知。模型加载本目录后应将图片作为外貌锚点，与 profile.md 外观查表互为补充（冲突时以图片为准）。

## 资源限制说明

绝大多数素材站有下载限制（登录 / 反爬 / 版权），本 skill **不自动抓取图片**，由用户手动下载后放入本文件夹。放入后无需改代码，模型按文件名自动识别。

**版权提醒**：本角色为米哈游《原神》官方角色，所有官方图版权归原作者所有，本目录图片仅作扮演时的外貌参考，不得用于商业用途。

## 命名规范

示例：

