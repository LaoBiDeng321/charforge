# 佩丽卡 · 外貌参考资源（assets/）

## 一、用途声明

本文件夹存放**角色立绘与外貌参考图**，供多模态模型在扮演启动时读取，建立"我长什么样"的外貌认知（加载规则见 `../SKILL.md` 的加载条目）。

- 纯文本模型可忽略本文件夹，不影响扮演。
- 本文件夹**不计入 10 个设定文件**：图片不是设定，只作外貌锚点；外貌文字要点见 `../profile.md`「外观速查」。
- **扮演输出中默认不引用文件名，也不出现"立绘"字样**（见 `../SKILL.md`）。
- **读取纪律**：多模态读取用于校准形象；**不因图片改变文字设定**（外貌文字要点以 `../profile.md` 为准）。

## 二、资源限制说明

- 绝大多数素材站有下载限制（**登录 / 反爬 / 版权**），本 skill **默认不自动抓取图片**，由用户手动下载后放入本文件夹。
- 本 skill 只输出放置说明，**不代下载、不代转存**。
- 请优先使用**官方渠道**；非官方转存（如游戏内资源拆包）请自行确认版权与清晰度，本 skill 不对其授权状态负责。

> ⚠️ 本角色是**本作看板娘**，其头像即游戏 APP 图标，官方素材渠道相对充裕，可优先从官网与官方社媒获取。

## 四、命名规范

- 新增文件统一格式：`<序号>-<内容>.<扩展名>`（序号两位、内容用中文短名），例如：
  - `02-头部特写-耳羽.png`
  - `04-表情-默认.png`、`04-表情-严肃.png`
  - `06-武器-施术单元.png`
- 同一角色的更新版本用 `-v2` 后缀，不覆盖旧图。
- **既有多图形态的角色**（如早期立绘 vs 实装立绘）请在文件名中显式标注版本，避免混淆。
