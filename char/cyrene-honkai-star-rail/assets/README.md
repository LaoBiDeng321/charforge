# 昔涟 · 外貌参考资源（assets/）

## 一、用途声明

本文件夹用于存放**角色官方立绘与外貌参考图**，供多模态模型在扮演启动时读取，建立"我长什么样"的外貌认知（加载规则见 `../SKILL.md`「外貌资源」）。

- 纯文本模型可忽略本文件夹，不影响扮演。
- 本文件夹**不计入 10 个设定文件**：图片不是设定，只作外貌锚点；外貌文字要点见 `../profile.md`「外观要点」。

## 二、资源限制说明

- 绝大多数素材站有下载限制（**登录 / 反爬 / 版权**），本 skill **默认不自动抓取图片**，由用户手动下载后放入本文件夹。
- 本 skill 只输出放置说明，**不代下载、不代转存**。
- 本次采集期间，官方站点在本机**不可访问**（已实测并记录）：官方 HoYoWiki 返回 `403 Our services are not available in your country or region`；米哈游官网角色页为 JS 空壳无正文；百度百科 403；维基百科连接失败。因此**下面的来源方向需要用户在自己的网络环境下自行获取**。
- 请优先使用**官方渠道**；非官方转存的图片请自行确认版权与清晰度，本 skill 不对其授权状态负责。

## 四、命名规范

- 统一格式：`<序号>-<内容>.<扩展名>`，序号两位、内容用中文短名。
- 示例：
  - `01-全身立绘-完全体.png`
  - `02-全身立绘-少女形态.png`
  - `03-全身立绘-迷迷.png`
  - `05-表情-默认.png`、`05-表情-认真.png`
  - `08-道具-仪式剑.png`
  - `11-联动造型-安踏-跟我一起出发.jpg`
- 全目录保持同一风格；同一角色的更新版本用 `-v2` 后缀，不覆盖旧图。
- 放置完成后通知执行方核对：届时会按本清单核查缺项，并把图片对应关系补进 `../profile.md`「外观要点」与 `../SKILL.md`「外貌资源」的引用。
